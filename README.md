# 食品工厂HACCP控制计划与偏差处置平台

独立React前端工程，采用Fluent UI、Redux Toolkit、RTK Query、React Router、Vite和TypeScript。数据通过浏览器持久化，无需后端。

## 功能

- 生产批次、放行状态、监测点与隔离范围。
- HACCP流程图和控制矩阵：记录关键限值、纠偏措施，以及**监控频率与生效时刻（频率版本链）**。
- **统一频率依据**：控制矩阵、批次监测、偏差处置、放行结论共用同一份频率版本：
  - 改频新增版本并指定生效时刻，只影响生效之后；相邻读数间隔严格大于当时生效频率即判一段断档（跨改频按分段判定，可结束于改频时刻）。
  - 断档批次先冻结放行并登记「监控断档」偏差；频率或读数变化时未确认断档自动重算并递增修订号，同一段断档重复重算不重复开偏差，不再成立的未确认断档自动撤销。
  - 补录读数只追加并另记录入时间/录入人，原有读数不改动；含补录的断档须偏差复核通过**且**补录后存在合格常规读数，批次才回到放行流程。
  - 升级前历史数据缺频率版本时先在控制矩阵回填基线，回填后才参与判定。
- 偏差登记、原因与证据调查、返工/报废分支、复核退回和签字。
- 未关闭偏差或未闭环断档阻止批次放行。
- 完整版本化审计和JSON追溯包导出。
